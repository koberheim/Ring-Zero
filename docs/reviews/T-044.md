& ./scripts/run_tests.ps1 -GodotExecutable 'E:/Godot/Godot_v4.7.2-stable_win64.exe' -SuiteTimeoutSeconds 120 -ImportTimeoutSeconds 90

The runner requires native Windows PowerShell 5.1 or PowerShell 7 on Windows, checks `4.7.2.stable.official.ed1daf0bf`, and needs neither Bash nor GNU timeout.
