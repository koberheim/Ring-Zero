# T-014 pressure data delivery

Added the required `pressure` object to the existing strict balance schema and testing JSON:

| Field | Testing value | Validation / units |
| --- | ---: | --- |
| spawn_per_second | 2.0 | Finite, nonnegative enemies/second |
| speed_ring_widths_per_second | 1.0 | Finite, positive ring widths/second |
| spawn_offset_ring_widths | 2.0 | Finite, positive ring widths |
| stat_increase_per_minute | 0.1 | Finite, nonnegative coefficient per minute |

These are approved D-017 testing values, not final density. Documentation states the final intent of hundreds or thousands of enemies and that the coefficient alone does not define a growth formula. Live spawning, timing/formula, effects on existing enemies, and caps remain outside this data foundation. The old documentation claim that no machine speed or spawn-rate data exists was replaced with the current data-only distinction.

Profile API and schema_version 1 are unchanged. Required fields use existing numeric validation rules, with no fallback/default literals in code. Test overrides may set spawn rate and escalation to zero; speed and offset must stay positive. Owned test fixtures derive from the shipped profile and needed no separate hand-authored schema update. No dependent fixture issue was encountered in the permitted files; consumer suite reruns belong to Astra review.

Focused validation: **271 balance checks, zero failures**, including all 141 prior checks and 130 added pressure checks. Coverage includes approved values, missing object/fields, unknown cap field, negative/nonfinite/bool/string/null/array rejection for every field, zero boundaries, fractional tuning, partial overrides, input/snapshot/section isolation, and JSON roundtrip with existing integer normalization preserved. An initial JSON-roundtrip assertion compared whole dictionaries across integer/float representations; it was corrected to check numeric field values explicitly, matching the existing API's non-integer numeric rules. Final suite passes without loader behavior changes.
