# T-025 private owned combat staging

Delivered one bounded optimization: public WeaponRules.step and private-convention WeaponRules._step_owned now delegate to a single _step_impl with an explicit target-copy policy. Target selection, geometry, cooldowns, ordering, damage, rewards, tolerances, and every validation/error path remain common. LiveSimulation uses the owned path only for its exclusive tick scratch. No core, presentation, profile, crowd, clock, or cadence change was made.

## Ownership and failure rules

Public step retains full purity: it duplicates target dictionaries/nested extras and clones PolarPosition objects. State/profile/cooldowns remain inputs, as before. Public targets_snapshot likewise still provides independently cloned positions.

_step_owned requires an exclusively owned array of target dictionaries. It may update scalar HP before a later error and returns that same owned target array on success. It never writes position fields or nested extra data, which may be borrowed read-only. All target/cooldown validation finishes before combat writes begin; there is no trusted-input bypass. Failure returns the original empty-result contract even when scratch HP was already consumed.

LiveSimulation already owns its staged dictionaries. On an owned-combat error it discards them and rolls back tentative admissions; pool HP/positions, build state, core, clock, cooldowns, events, navigation, and waypoints remain unchanged. Consumed admission lifetime IDs remain spent, as previously approved. On success it commits HP/position references and exposes only independent public snapshots/events. Scratch is never published via a public simulation result before commit.
