# T-021 shared wall routing and conditional wall combat

Implemented `WallNavigation`, integrated it with `LiveSimulation`, added required `standard_machine.wall_damage_multiplier: 0.25` with strict finite inclusive[0,1] validation, and updated owned tests/data documentation. No core, weapon, or presentation implementation was changed.

Navigation builds two shared PolarRouteFields over the same open-cell graph: exposed wedge/core goals and wall goals. Intact wedge interiors are excluded; broken/collapsed/unowned bands are traversable. Each node is its cell's inner curved boundary at center bearing. PolarGrid neighbors provide radial/angular connections, with96-unit radial costs and radius*TAU/12 arc costs. Machines query reachable exposed goals first, using wall fallback only when their component has none. This handles mixed-ring perimeters and core access without a12-wall shortcut or per-enemy searches.

The live service delegates segments to accepted PolarMotion, retaining private per-lifetime-ID endpoints across seams. Radial and angular segments remain polar and consume physical travel time; leftover time continues through nodes or applies DPS. On topology change, existing endpoints are reset and machines align radially then angularly inside their current open cell before routing. Tolerance-close PolarMotion reached=true/time_used=0 endpoints are consumed within the finite segment bound; only non-reached zero-progress results fail. No new movement tolerance or Cartesian authority was added.

A bounded topology fingerprint is checked at tick start. Topology-changing attacks set a staged dirty flag, so the fields rebuild before the next machine query in the same tick. Ordinary HP damage reuses fields. Horizon grows for historical/newly active bands and never shrinks because a farthest machine moves inward. Navigation, fingerprint, horizon, waypoints, and rebuild counters commit with gameplay; failed rule results preserve prior navigation and payloads while rolling back only tentative admissions. Their consumed lifetime IDs remain spent as previously approved. The preflight target snapshot now becomes the staged movement list, eliminating a duplicate full snapshot while preserving independent positions and lifetime order.

Walls use only the configured fraction of each machine's own DPS when exposed routes are unreachable. Active walls protect wedge HP. Wall death erases its record, emits one walls_broken event, gives no reward/refund, and stops that attack for the tick. Later IDs route through the new opening immediately. Support break makes retained walls inactive; whole-ring collapse erases every wall before tombstone validation. `place_wall` is an atomic live transaction with independent returned state, no building-slot use, no pause, and ended-run rejection.

The explicitly impossible old inner-collapse fixture was corrected: ring2/wedge7 is an already broken approach gap before placing a machine at band2/wedge7 to attack ring1. Other ring2 wedge HP, relay, historical identity, and outer-ring survival remain asserted. Intact-cell interior sources are now rejected before admissions. No other prior valid checks were removed.
