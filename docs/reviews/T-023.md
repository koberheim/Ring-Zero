# T-023 measured live-step cost correction

Source is frozen for Astra review. Changes are confined to owned live simulation/navigation source, their tests, this report, and generated local review data/logs. Core, WeaponRules, profile data, presentation, fixed60Hz, spawn rate, capacity, combat cadence, and rollback semantics are unchanged. T-021's duplicate snapshot removal was already present and is not claimed again.

The task first instrumented snapshot/preflight, route/movement, the WeaponRules call, and persistence independently. Private `_measure_costs` defaults false; clock reads and `_last_step_costs` updates are opt-in for the review fixture. A nested PolarMotion timer identifies its contribution within movement, not an additional additive phase. Phase medians do not necessarily sum to the independently measured total median. Instrumentation adds its own small timing/branch overhead and is identified in all sustained results.

Three corrections were measured one at a time:

1. WallNavigation precomputes route results once per immutable graph cell. Public route_for returns a deep independent copy, including its errors collection; invalid queries also return independent containers and do not expand the cache. The cache is bounded by cell count and replaced with the graph on topology changes. This primarily helps stationary attackers; ongoing waypoint motion rarely queries a route.
2. After Astra independently reviewed the contracts of PolarMotion and WeaponRules and explicitly approved the change, private staged target records retain read-only references to initial positions. Neither dependency mutates input positions. Motion replaces a staged position; WeaponRules clones returned positions before commit. Public targets_snapshot still clones every PolarPosition. Failed ticks preserve original payload position identity/value. No new sharing was introduced through a public result, and all existing staging/rollback rules remain.
3. Waypoint cleanup now checks EntityPool.contains(id), its confirmed O1 membership API, after releases. It avoids rebuilding a sorted active-ID snapshot and temporary membership dictionary. Stale endpoints for externally released test IDs are still erased, including when no active targets remain. Its measured sealed persistence gain is small; angular gain was within run variation.

Baseline and correction measurements used an exclusive Godot window coordinated with Astra. Astra confirmed neither root nor Luna ran Godot tests/measurements concurrently. Unrelated system load cannot be ruled out.

Results do not justify a final performance or crowd-cap claim.

This evidence supports a separate bounded Sol motion investigation; no core code was changed here. The rendered catch-up spiral reported by Luna is not solved by these modest gains alone, and no clock/delta/catch-up/rate changes were made.
