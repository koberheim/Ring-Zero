## API and behavior

`TerrainRules.place(state, profile, ring, wedge, slot, kind: StringName, direction: int = 1)` and `LiveSimulation.place_terrain(ring, wedge, slot, kind, direction = 1)` return `{ok: bool, state: Dictionary|null, errors: PackedStringArray}`. The pure result and successful live result are independently copied. IDs are `debris_field`, `tractor_lane`, `occlusion_screen`; records contain `kind`, with exact integer `direction` -1/+1 additionally required for Tractor. Helpers: `is_debris_blocking`, `tractor_direction` (0 inactive/absent), `has_screen`, `surface_speed_multiplier`.

Placement errors are `Invalid terrain or owned wedge`, `Wedge broken or slot invalid/occupied`, `Tractor direction must be -1 or 1`, `Wedge already has a Tractor Lane`, `Insufficient energy`, `Terrain would seal the outer frontier`, and live-only `Terrain would trap a living surface machine`; existing state/profile validation errors are forwarded. Ended live commands return `Run ended`. Navigation rejects missing numeric terrain data as `Terrain requires a balance profile`.

Pure placement and broken-to-intact Repair/Reclaim quotes validate the outer frontier against the complete candidate state. Their mutations share those quotes. Live wrappers additionally check living normal/roaming source cells and retain D-094 occupancy restrictions. Inside attackers and burrowers are excluded from open-cell requirements. Candidate checking uses local navigation; rejection spends nothing and preserves existing navigation/waypoints. Successful commands leave cache rebuilding to the existing staged tick fingerprint check before movement. Thus no failed tick commits a changed cache or machine position.

Debris masks both exposed and wall goals. Tractor discounts only its ordered outgoing angular arc and preserves reciprocal legality, exposed-before-wall category priority, and physical speed. Active support/effect/direction flags participate in the existing topology fingerprint; screen changes invalidate cached shadow coverage even if route connectivity is unchanged. Terrain-free navigation preserves the undirected path and avoids per-machine shadow work.

Shadow movement samples the open interval immediately ahead, including exact inward radial boundaries and both angular directions. A temporary angular boundary stop retains its original waypoint. Each adjacent-cell angular edge crosses at most one wedge boundary; boundary stops have their own `cell_count + 2` bound, while original node-cycle detection remains unchanged. Attack DPS, underground travel and cooldown time are unaffected. Strongest overlapping slow is applied once.

Defaults under D-033: costs 30/25/30 energy; Tractor route multiplier 0.5; Screen 3 outward rings at speed multiplier 0.5. Strict validated profile fields are documented in `docs/balance-data.md`. No existing numeric defaults changed.
