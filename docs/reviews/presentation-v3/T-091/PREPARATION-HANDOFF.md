# T-091 status/layout preparation for D and E

Preparation only, 2026-09-09; no shipping instrument change or human result yet.

`FortressStatus.records(authoritative_state) -> Array[Dictionary]` produces one new scalar-only record per ring. Existing fields `collapsed`, `wedges:Array[String]`, `relay_active`, `brownout` remain compatible with the existing HUD. Additions are exact `ring:int`, `relay_down:bool`, and `wedge_states:Array[Dictionary]` with `ring`, `wedge`, `status`, `hp`, `max_hp`, `health_fraction`, `broken`, `brownout`, `relay_down`, `lights_powered`.

Statuses are `ok`, `critical`, `broken`, `collapsed`; critical remains the existing <0.25 own-max-HP threshold. Relay failure is separate from healthy downstream relay in brownout. A collapsed ring is not mislabeled as merely a dead relay. Power comes from the existing `PowerRules.chain_boundary`; the fresh projection does not cache a past state. `lights_powered` is false for absent/dead/disconnected wedges. Visual lamp damage can additionally use `health_fraction`, without changing power output rules.

`IntegrityLayout.minimum_size(rings, local_to_physical) -> Vector2` gives the instrument's minimum local size so each painted ring band is >=6 physical pixels **after a1px separator**. At twelve rings and unit physical scale this is232x232; current264x264 may be retained/enlarged as layout permits. Core radius remains22% of outer radius, margin8 local units. Values are provisional presentation tokens. D must reserve an actual radar rectangle at least this minimum and pass the full Control-local-to-physical transform, not a guessed UI scale. A smaller host must reflow, never silently squeeze bands. No ring aggregation/scroll mechanic is introduced.

`geometry(size,rings)` returns center, outer/core radii, band width and ring count. `hit(local,shape,records)->Vector2i` and `focus_point(ring_index,wedge,shape)->Vector2` share exact clockwise clock-face mapping: north12, east3, south6, west9; ring0/core is `(0,0)`, outside is `(-1,-1)`. Ring IDs come from records, not assumed UI row IDs. Coordinates are local to the actual resized Control; the host converts physical pointer using its inverse transform. Existing `wedge_focus_requested(ring,wedge)` signal remains the proposed integration interface.

Planned static vocabulary: stronger healthy fill and continuous band; critical diamond; broken interrupted band plus X; relay-down crossed lamp at north; brownout lightning plus subdued/hatch band. Shape/pattern and color coexist, failure remains visible without flashing, and hover/focus identifies exact ring/wedge/state. The implementation must preserve12 separately inspectable rings, test grayscale/reduced-motion, and capture state-matched native1080/1440/ultrawide output. Timed9/10 human identification is pending.
