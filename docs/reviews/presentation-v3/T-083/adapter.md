# T-083 early collapse adapter

Technical interface frozen after 47/47 suites and native motion evidence. **T-083 is partial, not Done:** authored collapse audio, human comprehension, integrated final-core results flow and the dense-load performance failure remain open.

`live_view._simulation_tick(dt)` retains the pre-step `simulation.state` dictionary reference, calls the existing simulation step, and invokes `_presentation_committed_tick(before: Dictionary, events: Dictionary, tick: int)` only after success. The simulation replaces its state when committing; the hook copies only lost presentation geometry. No gameplay state, tick, targeting, rewards or time scale is changed. The hook runs inside each fixed tick, so a collapse cannot disappear between two ticks in one draw. Never replace this with polling `last_events` once per frame.

`release_view` implements that hook and owns `collapse_feedback` (`src/presentation/effects/collapse_feedback.gd`). `admit(before, events, tick)` returns `{id: StringName, point: Vector2}` cue records. Ring IDs in actual `collapsed_rings` produce one ring event; broken wedges within that same ring event are absorbed into its mass rather than duplicated. Other `broken_wedges` receive independent wedge events. Actual `core_lost` receives a short world emphasis. The adapter ignores repeated/older tick IDs and resets when simulation identity changes. It has no simulation RNG use.

Each retained event is `{kind: String, ring: int, tick: int, age: float, pieces: Array}`. A piece retains its PolarGrid-derived center/angle, thin band polygon/UV, open truss rails, actual hardware kind/slot/position/orientation and actual standing wall modules. Hardware uses the authoritative `slot_count`. These are cosmetic copies, not live state references. Current geometry matches the release view's 28-world-unit inner / 25-unit outer band width, its open radial rails and authored mount/head/wall textures. Future E geometry changes must update this representation together; do not reintroduce a filled 96-unit annulus or shifted bearing centers.

`advance(delta, paused, enabled)` freezes ages on pause, expires geometry at 2.8 seconds and immediately clears transient geometry when effects are off. `camera_impulse(camera.zoom, reduced_motion, effects)` returns a bounded camera offset: max9 stage pixels, with y zoom applied separately. D's physical viewport rewrite may change the old stage-to-root scaling; preserve a bounded pixel amplitude and transformed picking. Reduced motion and effects-off immediately zero the camera offset through `apply_interface_settings`. The original missing ring remains in authoritative state, with no static band/lamps after transient expiry. Retry/new simulation resets tick history; scene teardown releases all adapter data.

`draw(canvas, zoom, reduced_motion, art)` draws on the main world canvas, inside A's glow group <=0. `art` supplies `heads`, `mount`, `bands`, `wall`, `terrain`. Do not move this into the paired static caches or set them to UPDATE_ALWAYS. Paired cache invalidation still comes from actual changed fortress state. The adapter does not own either viewport, lighting uniforms, or HUD layers.
