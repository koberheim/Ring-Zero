# T-053 — Hotkeys and compact interim UI

Luna, 2026-09-07. **Frozen for aggregate review: 1002 focused functional checks and 26 rendered capture checks pass.** Astra inspected and accepted the final compact layout. All task-owned Godot processes exited. No gameplay/core/profile or main-scene changes.

## Layout plan and critique

T-051 reserves a 320-pixel catalogue with a fixed feedback area, plus a 220-pixel minimap and always-open art settings. Long button instructions and the tallest hidden tab occupy space regardless of the current action. The new layout will use a 260-pixel naturally sized catalogue at the left, separate always-reachable solar buttons, a 160-pixel minimap at the right, and an initially collapsed art drawer. A small top strip carries resources and session/help controls; selection and brief action/error context sit below it. Menu and help center against the actual viewport. No resize will alter the camera.

Physical-key dispatch will select through the existing button command paths, suppress tab-change cancellation only during programmatic category selection, and consume handled keys before GUI navigation. Successful build transactions keep their tool; each subsequent purchase still requires a distinct unhandled world press and authoritative validation. Solar casts remain one-shot. Escape closes help, then cancels an active tool, then toggles Menu.

Existing T-051 captures are the before-layout evidence. New captures and measured visible panel sizes will document both 1280×900 and 1024×768 layouts, including collapsed catalogue input pass-through. This is an interim usability pass; the experimental art direction and gameplay balance remain unchanged.

## Delivered behavior

The complete physical key map is in [CONTROLS.md](../CONTROLS.md). All mapped selections use the existing validated button paths. Programmatic category changes suppress only tab-change cancellation. Keyboard dispatch rejects echo/release, Ctrl/Alt/Meta, text focus and paused/ended gameplay before the live selection method can clear ability targeting. Escape closes help, then cancels a tool, then toggles Menu; closing an open Menu remains possible while paused. Right cancellation and middle-button release still work across GUI panels.

Build tools remain active after successful purchases, including expansion, repair and reclaim. Each distinct world press invokes one authoritative transaction; pointer motion, held buttons and echoed keys do not paint. Failures preserve tools and state. Successful expansion refreshes the next quoted price before showing the active-tool context. Ability casts remain one-shot, respect cooldown and do not cast from keypress alone. Menu, loss/error and Retry retain their existing clearing behavior.

Weapons, Structure and Terrain are simultaneously visible without tab scrolling. The catalogue is 260px wide, with measured heights of 184px / 216px / 152px respectively at both tested viewport sizes. The minimap is 160×160px, versus the prior 220×220px. Solar remains separately reachable at the lower left when the catalogue is collapsed. Art settings start collapsed behind F2. Menu/help positions follow viewport size; resizing controls does not change camera transform. Help has an 8px inset. The existing body font/theme remains; catalogue rows and category labels use readable 14px type.
