Tractor's explicit clockwise/counterclockwise button supplies+1/-1 before placement. Prompts explain Debris's outer-boundary blocking and Screen's outward-column slow. Selected occupant status shows the approved name, Tractor direction or Screen's actual outward ring span and speed percentage. Normal markers keep approved text labels; the experimental art view adds small recognizable terrain silhouettes, with the Tractor arrow following its actual direction. Broken support uses existing broken-state rendering and zero occupiable slots.

Focused Flare and EMP Burst are a separate two-button group below the build feedback, above Menu. Each displays ready or remaining cooldown. Ability targeting is separate from building: choosing either cancels the previous mode. Right click, Menu, loss/error and Retry clear it. World clicks cast only through unhandled input, while GUI-consumed motion/buttons hide the target preview without casting. Successful commands count `cast.events.kill_ids` once, sync targets immediately and retain zero ability energy reward; fixed-tick events are not replayed.

Flare's outline uses profile world range and arc about the core; EMP's circle uses profile radius about the pointer. Pointer conversion uses a temporary scalar PolarGrid sized from finite clicked radius, with no cells/polygons allocated and no displayed-world aiming cap. A ring8 EMP regression succeeds while build geometry stays at three rings. Pan and wheel first update the camera, then recompute the aim, so the displayed outline matches the next click. Invalid/nonfinite geometry is rejected or hidden safely, including an edited1e308 radius. Flare still needs a nonzero bearing.
