# T-019 outer-edge wall placement delivery

Implemented the approved independent wall placement layer in `src/gameplay/wall_rules.gd` and optional wall validation in `src/gameplay/ring_purchase_rules.gd`. New focused tests are `tests/gameplay/test_wall_rules.gd`; generated adjacent UID metadata is included. No runtime, core, balance, or UI files changed.

`WallRules.place` validates the complete state/profile, requires an existing unbroken owned wedge with no wall, uses current profile wall cost/HP, deducts once, and returns an independent deep copy. Walls live on the wedge's outer edge independently of normal slots. Existing Flak/relay occupancy, slot counts, relay references, profile, and caller state are preserved. Inner and outer owned wedges use the same data price; free-cost and fractional-HP tuning are supported.

The shared validator accepts absent walls and positive finite `{hp,max_hp}` records with HP no greater than max HP. It rejects extra/missing keys, wrong scalar/container types, bool/string/nonfinite amounts, zero/destroyed records, and walls on collapsed tombstones. A broken support may retain a positive wall record, but `is_blocking` returns false. That lightweight query also returns false for missing ring/wedge/wall and collapsed supports; it is explicitly not a whole-state validator.
