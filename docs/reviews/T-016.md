Delivered `MachineSpawnRules` with three independent APIs:

- `arrivals_between` describes the half-open schedule interval (start,end] using scalar counts. Sequence 1 is due at 0.5 seconds for the testing rate. Count boundaries use the approved 1e-12 tolerance in arrival-count units. Zero rate returns zero first sequence/count; positive empty intervals identify the next sequence. No arrival-sized array is allocated.

No entity ID or authoritative world vector is assigned.

Invalid/null/uninitialized profiles, invalid timing/identifiers, nonfinite calculations, and unrepresentable counts/rings return structured errors without partial results. Integer ring addition is guarded before computation. Constants are schedule units, approved numerical tolerance, integer representation bounds, and existing polar geometry constants; no gameplay fallback values were introduced.
