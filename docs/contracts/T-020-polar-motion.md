# T-020 - Constant-speed radial and angular motion

Owner: Sol. No delegation. Own src/core/polar_motion.gd, tests/core/test_polar_motion.gd, docs/reviews/T-020.md and generated metadata. Read owned files and this brief only. This utility follows supplied targets; it chooses no gameplay route or attack.

PolarMotion extends RefCounted. static advance(current:PolarPosition,target:PolarPosition,speed_world:float,delta_seconds:float)->Dictionary {ok:bool,position:PolarPosition or null,time_used:float,reached:bool,errors:PackedStringArray}. Valid positions here are outside the core: ring>=1,wedge1..12,finite radial/angular fractions in[0,1). Constructor PolarPosition.new(ring,wedge,radial_fraction,angular_fraction). RING_WIDTH=96, CORE_RADIUS=96 from PolarGrid constants. No Cartesian authoritative position.

Convert using scalar radius = CORE_RADIUS+(ring-1+radial_fraction)*RING_WIDTH; bearing turns=(wedge%12)/12-1/24+angular_fraction/12, normalized modulo1. Accept a single radial segment (same bearing) or angular arc (same radius), including identical endpoints. Reject endpoints differing in both radius and bearing. Use documented roundoff tolerance at most1e-8 world units and1e-12 turns for equality; no broad geometry snapping. Input validation includes finite positive speed and finite nonnegative delta. Invalid returns null position,time_used0,reachedfalse,errors; never mutate inputs.

Radial distance=absolute radius difference; angular distance=shortest angular difference in turns * TAU * radius. Exact half-turn tie goes clockwise. Travel at constant supplied world speed, consuming min(delta,distance/speed); if the endpoint is reached, return an independent exact clone of target with correct consumed time so caller can use leftover time. Otherwise construct the interpolated PolarPosition, with outward band ownership at exact radial boundaries and clockwise wedge ownership at angular seams. No artificial delay when reaching a target. Zero delta returns cloned current unless already equal; equal endpoints use time0/reachedtrue.

Reject computed nonfinite/unrepresentable radius/distance/time/band IDs clearly; no wrapping signed integers or looping once per crossed cell. Do not use single-precision Vector2 conversion as authoritative interpolation. This utility permits long legal one-axis segments but does not know barriers; callers supply traversable segments only. No path graph, pooling, gameplay, scene or existing core edits.
