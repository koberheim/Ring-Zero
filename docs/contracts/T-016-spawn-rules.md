# T-016 - Deterministic testing spawn schedule and machine stats

Owner: Terra. No delegation. Own src/gameplay/machine_spawn_rules.gd, tests/gameplay/test_machine_spawn_rules.gd, docs/reviews/T-016.md and generated .uid files. Read owned files and this brief only. No live scene, movement, damage, pool, balance schema or other implementation edits.

Approved: D-017 testing rate 2/sec, speed 1 ring width/sec, offset 2 ring widths beyond the OUTER boundary of the outer owned ring, even bearing coverage. D-053: each completed minute adds 10% of original HP and DPS to NEW spawns only. Existing enemies keep spawn stats. Final gameplay favors larger swarms of weaker enemies; this additive curve is testing only. All values come from BalanceProfile.value(dot_path), not fallback literals.

Implement MachineSpawnRules extends RefCounted with static methods:
- stats_at(profile:BalanceProfile, elapsed_seconds:float)->{ok,stats:Dictionary or null,errors:PackedStringArray}. Validate profile via BalanceProfile.from_dict(profile.snapshot()).ok (null/uninitialized invalid) and finite elapsed>=0. stats keys hp, damage_per_second, speed_ring_widths_per_second. factor = 1 + floor(elapsed/60) * pressure.stat_increase_per_minute. HP uses health.standard_machine_hp, DPS standard_machine.damage_per_second. Reject nonfinite computed stats. No rounding health/damage to integers.
- arrivals_between(profile:BalanceProfile, start_seconds:float,end_seconds:float)->{ok,first_sequence:int,count:int,errors:PackedStringArray}. Interval is (start,end], zero-length valid, finite 0<=start<=end. Sequence numbers start at 1; spawn n is due at n/rate, so first default arrival is 0.5 seconds. Rate zero returns first_sequence=0,count=0. Compute using floor(time*rate) with a documented tiny roundoff tolerance (1e-12 in arrival-count units); no array allocation proportional to elapsed time. Reject nonfinite/unrepresentable integer counts or overflow. Positive-rate empty interval reports first_sequence=previous_count+1; impossible representability fails clearly. This describes arrivals only, not capacity policy or admitting them.
- spawn_descriptor(profile:BalanceProfile, sequence:int,outer_ring:int)->{ok,spawn:Dictionary or null,errors:PackedStringArray}. sequence>=1,outer_ring>=0,positive rate required. due time=sequence/rate; use stats_at at that due time. Stable even coverage: sequence1 at wedge12 center, then wedge1..11, repeat. This is a deterministic test schedule, not randomness or a final variety rule. Spawn radius = PolarGrid.CORE_RADIUS + outer_ring*PolarGrid.RING_WIDTH + pressure.spawn_offset_ring_widths*PolarGrid.RING_WIDTH. Return spawn {sequence:int,elapsed_seconds:float,position:PolarPosition,hp:float,damage_per_second:float,speed_ring_widths_per_second:float}. PolarPosition constructor(ring:int,wedge:int,radial_fraction:float,angular_fraction:float), fractions [0,1). At exact band boundary choose outward band; use ring=outer_ring+floor(offset)+1, radial_fraction=offset-floor(offset), angular_fraction=.5; never store authoritative world vectors. Constants CORE_RADIUS=96,RING_WIDTH=96; no geometry conversion needed. Validate resulting ring fits signed integer and scalar radius finite. Return independently owned descriptor/position each call. No entity ID is assigned here; pool assigns lifetime IDs later.

Existing APIs: BalanceProfile.load_json("res://data/balance/testing.json")->{ok,profile,errors}, with_overrides(nested Dictionary)->same, snapshot()->deep copy. Required profile fields pressure.spawn_per_second, pressure.speed_ring_widths_per_second, pressure.spawn_offset_ring_widths, pressure.stat_increase_per_minute. Preserve caller state; do not update existing target dictionaries.
