# Presentation replacement — September 8, 2026

Kevin rejected the first release candidate's generic interface, weak structure art,
flat sun and low apparent resolution. This pass replaces that presentation on
`release/v1.0-candidate`; the earlier local QA results do not constitute visual
acceptance. Kevin explicitly authorized parallel agents and offered the open
Blender session as an optional production tool.

## Shared visual contract

The established world direction remains lit industrial hardware, painterly light
and mostly open void. The interface takes its identity from spacecraft
instrumentation: near-black navy, warm ivory, brass rails, amber status lights
and restrained cold cyan. Typography, composition, material depth and meaningful
hierarchy must carry the design. Generic gray cards and a flat noise disc are
not adequate acceptance results.

The game renders to a native 2560 × 1440 stage. The initial desktop window is
1920 × 1080, with aspect-preserving downsampling and smaller-window compatibility.
World coordinates remain unchanged. All pointer conversion goes through the
frame and viewport transforms. There is no enlarged 1440 × 810 intermediate.

WASD controls map movement. Wall moves to H, Debris to C, Tractor Lane to V and
Occlusion Screen to B. Existing configurable inputs migrate without changing the
internal command identifiers or losing customized bindings.

## Delivery ownership

- Presentation agent: application pages, shared theme, and live HUD layout.
- World-art agent: fortress renderer, sun and world shaders, authored asset use.
- Input agent: binding migration, continuous camera movement, controller bounds.
- Astra: integration, resolution settings, independent visual review, regression
  tests, native rendered performance, package interaction, commits and report.

Acceptance requires viewing actual game captures at 1440p and 1080p, checking
opening and crowded gameplay as well as menus, testing transformed input after
window changes, verifying keyboard navigation and preserved profile behavior,
and producing a fresh identified Windows package. Gameplay scope, reward rules
and Steam account integration are not expanded by this visual correction.
