## Navigation contract and geometry

WallNavigation extends RefCounted. static build(state:Dictionary,outer_band:int)->{ok,navigation:WallNavigation or null,errors:PackedStringArray}; caller first validates build state/profile. Reject outer_band<1 or insufficient to contain all historical rings plus one outer band. For each band1..outer_band/wedge1..12, include a traversable cell if no historical ring occupies that band OR it is collapsed OR that wedge.hp==0. Intact owned wedge interiors are impassable. Core cell(0,0) is not a movement cell: machines stop at its outer surface.

Represent each open cell(r,w) by node PolarPosition(r,w,0,.5), its INNER curved boundary at radius96+(r-1)*96 and center bearing. This keeps surface contact consistent with T-017 and avoids a half-band detour to cell centers. Include every legal radial/angular connection between open cells. Radial cost=96; angular cost=node radius*TAU/12, the physical arc length between center bearings. No diagonal/chord cuts through wedges. Use supplied PolarGrid.cell_neighbors (exclude core0), PolarRouteField below. Keep world vectors transient/unused for authority.

An open cell(r,w) is an exposed goal if r==1 (core outer surface), or if inward wedge(r-1,w) is intact and WallRules.is_blocking is false. An intact inward wedge with active wall is a wall goal. Build TWO shared fields over the same graph: exposed goals, and wall goals. For each machine, query the exposed field first. Only if unreachable use the wall field. This resolves reachable connected regions, including uneven mixed-ring perimeters, without per-machine searches or an all12-on-one-ring shortcut. Core reachability counts as an exposed destination and prevents needless wall attacks.

navigation.route_for(cell:Vector2i)->{ok:bool,next_cell:Vector2i,goal_cell:Vector2i,target_kind:StringName,target_cell:Vector2i,errors:PackedStringArray}. target_kind is &"core", &"wedge", or &"wall"; target_cell is ZERO for core, otherwise goal_cell-(1,0). next_cell and goal_cell come from selected field. Fail on nontraversable/unreachable source with sentinel(-1,-1), empty kind; do not teleport/wait silently. Equal-cost rules are the existing field's lowest goal then lowest next cell ordering.
