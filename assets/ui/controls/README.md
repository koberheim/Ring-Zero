# Instrument controls

Original vector assets authored for RING ZERO under T-086. No generated bitmap, external font outline or third-party asset was used. The lettering is drawn as geometric paths so engine SVG import has no font dependency.

The toggle is a two-position industrial selector: restrained steel / left / OFF versus warm amber / right / ON. Disabled variants preserve the position and words in neutral metal. The dropdown arrow uses the same engraved-bar vocabulary. Hover and focus belong to the row's theme, leaving the switch state legible during interaction.

Provisional dimensions: switch 104×36 native pixels; thumb 29×24; lettering 12 pixels tall with 2-pixel strokes; arrow 24×24. At the current 1080p fit the switch is 78×27 physical pixels. UI scale affects row typography while the switch retains this minimum readable footprint.
